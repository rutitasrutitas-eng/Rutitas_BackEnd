## Criterios

- Los documentos pertenecen al proyecto Backend y citan únicamente su Constitución como autoridad local.
- Los requisitos ARCH-BE-xx están destinados a arquitectura base, sin features del producto.
- `task.md` describe siete tareas futuras sin iniciar; AGENTS prohíbe ejecutarlas en esta fase.
- No se selecciona stack ni se atribuye aprobación a agentes o skills.
- El documento de integración no obliga automáticamente a Móvil/Backend externo.
