# Subagentes — Backend

Índice de definiciones de agentes destinadas a OpenCode y específicas de Backend. Los archivos están en `.opencode/agents/`; su descubrimiento o ejecución en cualquier runtime no está validado. La Constitución propia prevalece.

- [Arquitecto Backend](../.opencode/agents/backend-arquitecto.md) — Estructura de Backend, capas conceptuales, modularidad, configuración, persistencia abstracta y observabilidad.
- [Revisor de límites y contratos](../.opencode/agents/backend-revisor-contratos.md) — Interfaces entre capas y futuro intercambio con clientes, errores y compatibilidad sin operaciones concretas.
- [Revisor SDD Backend](../.opencode/agents/backend-revisor-sdd.md) — Alineación entre Constitución propia, AGENTS, spec, plan y task de Backend.
- [Revisor de seguridad Backend](../.opencode/agents/backend-revisor-seguridad.md) — Protección de datos, secretos, autorización del lado del servidor y riesgos de infraestructura como principios.
- [Revisor de calidad Backend](../.opencode/agents/backend-revisor-calidad.md) — Requisitos verificables, modularidad, mantenibilidad, logging y pruebas futuras.

**Compatibilidad:** las definiciones enlazadas están en formato OpenCode bajo `.opencode/agents/`. No se declaran instaladas, descubiertas o funcionales en Codex. No se ejecutan agentes en esta fase.
